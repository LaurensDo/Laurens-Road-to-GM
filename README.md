# Road to GM

Persönliche Schach-Trainings-App: analysiert alle Partien von lichess und chess.com, findet heraus, wo Punkte verloren gehen, und baut daraus ein tägliches Training aus den eigenen Stellungen.

Status: Version 1.1 im Einsatz auf iPhone und iPad (Abgleich über GitHub), Phase 2 offen.

- App: https://laurensdo.github.io/Laurens-Road-to-GM/, Code und Aufbau in [`app/`](app/README.md)
- Diagnose und Übungen: [`analysis/`](analysis/README.md)
